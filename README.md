# Flappy-Bird
Данная игра сделана на языке Python. В  ней наш персонад двигается вперед через появляющиеся трубы, трубы появляются с разной высотой, если персонаж столкнется с трубой ты мы проиграли.
Управление персонажа W или стрелка вверх.
